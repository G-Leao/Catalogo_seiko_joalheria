# ⌚ Catálogo Seiko — Gravina

> Catálogo digital premium desenvolvido para apresentar uma seleção de relógios **Seiko**, proporcionando uma experiência moderna, elegante e intuitiva para descoberta dos modelos e contato com a equipe.

🔗 **[Acessar projeto online](https://catalogo-seiko-joalheria.vercel.app/)**

---

## ✨ Sobre o projeto

O **Catálogo Seiko — Gravina** é uma experiência web desenvolvida para apresentar uma seleção de relógios Seiko de forma sofisticada e responsiva.

O projeto foi pensado para unir **design premium, navegação intuitiva e experiência de usuário**, permitindo que o visitante explore os modelos disponíveis, pesquise por referências e entre em contato diretamente com a equipe.

A interface utiliza uma abordagem visual inspirada no universo da relojoaria de luxo, valorizando tipografia, espaçamento, imagens e hierarquia visual.

## 🖥️ Preview

### Página inicial

A página inicial apresenta a marca, uma seleção de relógios em destaque e uma chamada para exploração do catálogo.

### Catálogo

Área dedicada à apresentação dos modelos disponíveis, com sistema de busca para facilitar a localização de um relógio específico.

Seção institucional apresentando a história e tradição da Seiko na relojoaria japonesa.

Integração com WhatsApp para facilitar o contato entre o visitante e a equipe da Gravina.

O principal objetivo do projeto é transformar um catálogo tradicional de produtos em uma **experiência digital mais envolvente e sofisticada**.
